# Акцент · Accent

Небольшое приложение для macOS, которое делает курсор, клики и сочетания клавиш заметнее на лекциях, вебинарах и записях экрана.

Тонкое кольцо с прозрачным центром помогает следить за указателем и оставляет содержимое под ним открытым. Системный цвет, нативные элементы управления и стеклянная плашка сочетаний подстраиваются под оформление macOS.

**[Скачать последнюю версию](https://github.com/archetypetrickster-tech/accent-pointer/releases/latest)**

## Возможности

- Кольцо вокруг курсора: размер, толщина, яркость и цвет. По умолчанию — системный акцент macOS.
- Без движения кольцо становится менее ярким. При удержании кнопки — немного плотнее.
- **Левый клик:** одна расходящаяся волна. Цвет настраивается отдельно через системную палитру macOS.
- **Правый клик:** две расходящиеся волны. Цвет настраивается независимо от левого клика и кольца курсора. Выбранные цвета также применяются к кольцу при удержании кнопки.
- Плашка сочетаний клавиш: команды с ⌘, ⌃, ⌥, а также F1–F20. Обычный текст, отдельные модификаторы и Shift + буква не выводятся.
- Повторяющиеся сочетания показываются со счётчиком. Обозначения букв — в стандартной латинской раскладке.
- Настройки положения плашки и времени показа.
- **Control + Option + P (⌃⌥P)** — пауза или включение всех эффектов, в том числе из других приложений.
- Управление из окна и значка в строке меню. **⌘Q** или «Выйти» полностью закрывает программу.
- Эффекты пропускают клики к приложениям под ними.
- Стеклянная плашка на macOS 26 и новее, системный материал на более ранних версиях. Учитываются настройки уменьшения движения.

## Установка

Требования: **Mac с Apple Silicon (M1 и новее), macOS 14 или новее**. Первая версия собрана и запущена на macOS 27.3. Сборки для Intel пока нет.

1. Откройте [Releases](https://github.com/archetypetrickster-tech/accent-pointer/releases/latest) и скачайте `Accent-0.1.4-macOS-arm64.zip`.
2. Распакуйте архив и перенесите **«Акцент.app» в «Программы»**. Если приложение уже установлено, сначала закройте его и замените существующую копию.
3. Запустите «Акцент». Курсор и клики работают сразу.
4. Для сочетаний нажмите **«Разрешить»** в окне приложения. В **Системных настройках → Конфиденциальность и безопасность → Мониторинг ввода** включите **«Акцент»**. Если macOS попросит перезапуск, закройте и снова откройте приложение.

Архив первой версии подписан локальной подписью, без нотариального заверения Apple. На другом Mac macOS может заблокировать первый запуск. Для осознанного запуска скачанной сборки используйте штатную кнопку **«Всё равно открыть»** в разделе «Конфиденциальность и безопасность». Альтернатива — собрать приложение самостоятельно из исходников ниже.

## Использование

1. Настройте кольцо так, чтобы оно было заметным на вашем рабочем фоне. Начальные значения: диаметр 50, толщина 2,4, яркость 85%.
2. В разделе «Клики» нажмите цветной образец рядом с «Левый клик» или «Правый клик», чтобы выбрать любой цвет. «Сбросить цвета» возвращает исходное поведение: левый следует цвету курсора, правый получает дополнительный цвет.
3. Нажмите «Проверить эффекты», чтобы увидеть пример плашки. Эта кнопка показывает образец даже до выдачи разрешения клавиатуре.
4. Для проверки реального ввода нажмите, например, ⌘C. Для паузы — ⌃⌥P.
5. Закрытие окна настроек оставляет эффекты включёнными. Вернуть окно можно через Dock или значок в строке меню. Полный выход — кнопка «Выйти», меню или ⌘Q.

Для лекции начинайте с **демонстрации всего экрана**. При показе отдельного окна сервис может не захватить слой эффектов. Перед эфиром проверьте изображение со стороны зрителя. Совместимость с конкретными сервисами вебинаров пока не проверялась.

На нескольких мониторах курсор следует за мышью, плашка появляется на мониторе с указателем. Конфигурации с несколькими физическими мониторами и полноэкранными приложениями требуют отдельной проверки.

## Конфиденциальность

Приложение работает локально, без сети, аналитики, аккаунтов и записи экрана. Нажатия не сохраняются и не отправляются. Сохраняются только настройки внешнего вида. Клавиатура прослушивается пассивно для показа сочетаний; на паузе и при выключенном показе сочетаний прослушивание останавливается. При защищённом вводе macOS плашка скрывается.

Разрешение на запись экрана для работы приложения не требуется. Для глобального показа сочетаний нужен «Мониторинг ввода». Если сочетание паузы занято другой программой, приложение сообщает об этом; кнопка и меню продолжают работать.

## Сборка из исходников

Нужны инструменты командной строки Xcode с Swift и SDK macOS 26 или новее. Текущая сборка использует Swift 6.4.2 в режиме совместимости Swift 5. Внешних зависимостей нет.

```sh
git clone https://github.com/archetypetrickster-tech/accent-pointer.git
cd accent-pointer
./build.sh
open outputs/Акцент.app
```

Скрипт генерирует иконку, собирает приложение, подписывает его локально и запускает 25 проверок фильтрации сочетаний, положения плашки и сохранения настроек. Чтобы собрать ZIP для распространения:

```sh
./package.sh
```

Исходники: `Sources/AccentPointer`. Иконка: `Tools/Icon.swift`. Проверки можно запустить отдельно:

```sh
outputs/Акцент.app/Contents/MacOS/Accent --self-test
```
